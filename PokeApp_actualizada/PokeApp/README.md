# PokeApp
WebApp Pokédex hecha con HTML5 + CSS3 + JavaScript (módulos ES, sin librerías).

## Cómo ejecutarla
Los módulos ES no funcionan abriendo el archivo con doble clic (file://). Usá un servidor local:
- VS Code: extensión **Live Server** → "Go Live", o
- Terminal: `python -m http.server 8000` y abrí http://localhost:8000
